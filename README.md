# hospital-triage-management-system
A c++ and DSA based hospital triage system that prioritizes patient based on emergency severity and arrival time.
## Project Objective 
The system helps hospitals  to manage patients by ensuring that patients with more serious medical conditions are attended first.

## Current features 
-Patient registration 
-Emergency severity based prioritization
-Arrival time consideration
-Patient queue mangement

## Technologies Used
-C++
-Data Structures and Algorithms
